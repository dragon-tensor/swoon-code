# Responsible use and project status

## Educational purpose

Swoon Code is an experimental, educational demonstration of the Autonomous Engine Markdown
Language (AEML) and the interpreter boundary around an agent. It exists to show protocol parsing,
capability validation, session isolation, confirmation, sandboxing, and consumer packaging. It is
not designed or intended to cause harm, facilitate violence or abuse, evade safeguards, bypass
access controls, or violate a service provider's rules.
