# Support

Swoon Code is an experimental educational project, not a hosted service. Community support is
best-effort through [GitHub Issues](https://github.com/dragon-tensor/swoon-code/issues).

Before opening an issue:

1. Use a supported Python and Linux environment from
   [`docs/supported-scope.md`](docs/supported-scope.md).
2. Run `swoon doctor` and the offline checks in
   [`docs/consumer-testing.md`](docs/consumer-testing.md).
3. Search existing issues and reproduce with the current default branch or latest release.
4. Remove credentials, private paths, source content, session output, and account identifiers.

Include the Swoon version/commit, Python version, operating system and architecture, exact redacted
command, exit code, and the smallest non-sensitive reproduction. Do not attach cookie files,
storage state, screenshots of authenticated pages, or an entire private session directory.

Maintainers cannot provide ChatGPT account support, approve a use under provider terms, accept a
user's credentials, recover deleted sessions, or promise compatibility with an unversioned web UI.
Report suspected Swoon vulnerabilities privately as described in [`SECURITY.md`](SECURITY.md).
